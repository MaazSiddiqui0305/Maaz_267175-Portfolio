# Maaz Siddiqui — Personal Portfolio

A responsive personal portfolio website created for a college assignment. It introduces the developer, lists technical skills, showcases two project examples, and includes a contact form with browser-side validation.

## Technologies used
- HTML5 — semantic page structure
- CSS3 — styling, responsive layout, hover effects, and media queries
- JavaScript — mobile navigation and contact form validation

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Edit the personal details and project descriptions to reflect your own work.

## Notes
The contact form performs front-end validation only. It does not send or store messages. Do not add passwords, private contact details, or your home address to this public repository.
